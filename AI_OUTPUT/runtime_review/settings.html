AI BRIDGE

Settings

Appearance, sync, provider health, updates, and runtime power controls. These settings are isolated from the relay engine.

Appearance

Theme changes apply immediately. Dashboard layout is saved immediately and is applied when you return to the Dashboard. You can also drag the splitter there.

Portable settingsLocal only

Push/Pull syncs appearance and reusable team preferences. It never syncs transcripts, Vault files, tab IDs, access tokens, or a live session.

Google Drive app dataNot linked

Optional second copy in your private Google Drive appDataFolder. Uses OAuth PKCE; the client ID stays local and tokens are kept in Chrome session storage.

Provider HealthNot checked

Checks the currently open supported AI tabs and verifies the AI Bridge content script responds. This is informational and does not alter relay state.

Runtime powerReleased

Uses Chrome's power API. Turning it off immediately releases the keep-awake request.

Updates

Checks this repository's main/manifest.json. AI Bridge never overwrites an unpacked extension automatically.
